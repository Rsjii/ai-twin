## OVERVIEW
- Dedicated page: `/public-chat/history`
- Access points: Dashboard + Discover page
- Shows all twins user chatted with
- Per twin: total chats count, latest preview, last activity

## PHASE 1: BACKEND - API Enhancement (Optional)

### Step 1.1: Enhanced API endpoint (optional)
- Reason: Abhi API latest chat hi deti hai. Agar per-twin chat count chahiye, to new endpoint banao.
- File: `backend/src/modules/chat/publicChatController.ts`
- Function: `getUserPublicChatsWithCount()`
- Logic:
  ```sql
  SELECT 
    t.id, t."publicHandle", t.bio, t."profileImage", ...
    COUNT(DISTINCT pc.id) as total_chats,
    MAX(pc."lastActivity") as latest_activity
  FROM "PublicChat" pc
  JOIN "Twin" t ON pc."twinId" = t.id
  WHERE pc."userId" = $1
  GROUP BY t.id, ...
  ORDER BY latest_activity DESC
  ```
- Endpoint: `GET /api/public-chat/user/my-chats-detailed`
- Alternative: Frontend me existing API se count karlo (simpler)
