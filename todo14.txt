## Final header structure

### Header layout (left to right)
```
[LOGO] → [Dashboard] [Discover] [Chat] → [Theme Toggle] → [Profile Photo Dropdown]
```

### Main header (always visible when logged in)
1. Logo — TwinOS (clickable, goes to dashboard)
2. Navigation links (horizontal):
   - Dashboard
   - Discover
   - Chat
3. Theme toggle button (always visible, logged in or not)
4. Profile photo button (with dropdown)

### Profile dropdown menu (when clicking profile photo)
1. User info section (top):
   - Large profile photo/avatar
   - Name/Handle
   - Email
   - Status badge (if applicable)
2. Navigation items:
   - Profile Settings
   - My Twin (if has twins)
   - Analytics
   - Settings
3. Divider
4. Sign Out

### When not logged in
- Logo → Home
- Discover link (always visible important hai not logged in user bhi public chat kar sake)
- Theme toggle (always visible)

### Phase 3: Fix all controllers

Ensure every controller passes `user`:

```typescript
// Standard pattern
res.render('page-name', {
  title: 'Page Title - AI Twin',
  user: req.user || null,  // Always pass, even if null
  hasTwins: hasTwins || false,  // If needed
  twinId: twinId || null,  // If needed
  csrfToken: res.locals['csrfToken']
```
