Based on research and best practices:

#### Background colors

```css
/* Dark Theme Text */
```

```css
/* Dark Theme Accents - Vibrant & Glowing */
--accent-primary: #3b82f6;      /* Blue 500 - Primary actions */

```

#### Button colors (dark-specific)
```css
/* Dark Theme Buttons */

.btn-secondary-dark {
  background: linear-gradient(135deg, #8b5cf6 0%, #7c3aed 100%);
  color: white;
  box-shadow: 0 4px 14px 0 rgba(139, 92, 246, 0.4);
}

.btn-accent-dark {
  background: linear-gradient(135deg, #06b6d4 0%, #0891b2 100%);
  color: white;
  box-shadow: 0 4px 14px 0 rgba(6, 182, 212, 0.4);
}
```

#### Card colors
```css
/* Dark Theme Cards */
.card-dark {
  background: rgba(30, 41, 59, 0.8);

.card-dark:hover {
  background: rgba(30, 41, 59, 0.95);

```

#### Border colors
```css
/* Dark Theme Borders */
--border-primary: rgba(51, 65, 85, 0.5);

```

### Implementation strategy

1. Create a centralized dark theme CSS file or add to `layout.ejs`

3. Test all components in dark mode
4. Ensure contrast ratios meet WCAG AA (4.5:1 for text)

### Specific component updates

1. Buttons
   - Primary: Blue gradient with glow
   - Secondary: Purple gradient
   - Success: Emerald with glow
   - Danger: Red with glow
   - All buttons: enhanced shadows in dark mode

2. Cards
   - Background: `rgba(30, 41, 59, 0.8)`
   - Border: subtle glow on hover
   - Shadow: colored shadows based on content

3. Inputs
   - Background: `#1e293b`
   - Border: `rgba(59, 130, 246, 0.3)` on focus
   - Text: `#f1f5f9`

4. Links
   - Color: `#3b82f6`

   - Use vibrant colors in dark mode
