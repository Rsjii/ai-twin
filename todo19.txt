### 1. Blocked user behavior — logic kya honi chahiye

- Blocked user → Chat blocked (message send nahi ho sakta)
- Blocked user → Profile visible (dekh sakta hai)
- No check in `getPublicProfile` for blocked users

Platform reference:
- Facebook/Instagram: Blocked user profile hide (404 or "Content unavailable")
- X (Twitter): Blocked user public posts dekh sakta, interact nahi kar sakta
- LinkedIn: Blocked user profile hide

Recommendation: Profile hide karein (Facebook/Instagram style)

Implementation:
```typescript
// In getPublicProfile (publicPageController.ts)
// Add blocked user check:
if (req.user) {
  const blockedCheck = await db.query(`
    SELECT id FROM "TwinBlockedUsers"
    WHERE "twinId" = $1 AND "userId" = $2

  if (blockedCheck.rows.length > 0) {

    });
```

Logic:
- Blocked user → Profile hide (404)

### 2. allowShares vs blockUser vs hideProfile — difference

Current:
- `allowShares`: Sharing button hide/show
- `blockUser`: Specific user ko block (chat blocked, profile visible)
- `hideProfile`: Not implemented

Differences:

| Feature | allowShares | blockUser | hideProfile |
|---------|-------------|-----------|-------------|
| Scope | All users | Specific user | All users |
| Purpose | Control sharing | Block specific user | Hide entire profile |
| Effect | Share button hide | Chat + Profile hide | Profile completely hidden |
| Use Case | "Don't let anyone share" | "Block this person" | "Make profile private" |

Recommendation:
- Keep `allowShares` (needed) — sharing control
- Keep `blockUser` (needed) — specific blocking
- Add `hideProfile` (optional) — profile visibility control

Structure:
```
Privacy & Interactions:
├─ Social Interactions:
│  ├─ Allow Likes [Toggle] ✅
│  ├─ Allow Follows [Toggle] ✅
│  └─ Allow Shares [Toggle] ✅ (Keep - needed)
│
├─ Blocked Users: ✅ (Keep - needed)
│  └─ [List of blocked users + Block button]
│
└─ Profile Visibility: (NEW - Optional)
   ├─ Public [Default]
   ├─ Private (only followers)
   └─ Hidden (only owner)
```

When to use:
- `allowShares = false` → Share button hide (profile visible)
- `blockUser` → Specific user ko block (profile + chat hide)
- `hideProfile = true` → Profile completely hidden (all users)

Recommendation: Keep both, with clear purpose

Ideal structure:
```
Twin Profile (/@handle):
├─ Purpose: View specific twin
├─ Shows: Twin details, stats, chat option
├─ Creator: "Created by @userHandle" (small link)
├─ Navigation: Click creator → User profile

   - Share twin
   - Chat with twin

User Profile (/user/:handle):
├─ Purpose: View user + their work
├─ Shows: User info + all their public twins
├─ Creator: User is main focus
├─ Navigation: Click twin → Twin profile
└─ Use Cases:
   - Analytics click (who liked/followed/chatted)
   - View user's creations
   - Discover creator
```

Where to show what:
- Analytics details → User profile (shows who interacted)
- Discover page → Twin profile (main entity)
- Share links → Twin profile (what's being shared)
- Search results → Both (twin + user)
