## 🎯 Recommended structure

### Section 1: Social engagement (clickable cards)
Row 1: 3 cards in one line
```
┌─────────────┬─────────────┬─────────────┐
│ Total Chats  │ Total Likes  │ Total       │
│ (Clickable)  │ (Clickable)  │ Followers   │
│              │              │ (Clickable) │
└─────────────┴─────────────┴─────────────┘
```

- Total Chats → Shows list of chatters
- Total Likes → Shows list of likers
- Total Followers → Shows list of followers

---

### Section 2: Analytics & insights (non-clickable, info cards)
Row 2: 2 cards in one line
```
┌─────────────────────┬─────────────────────┐
│ Total Views         │ Twin Performance     │
│ (Info only)         │ (Info only)          │
│                     │ - Memory: X facts    │
│                     │ - IQ Growth: +X%     │
└─────────────────────┴─────────────────────┘
```

- Total Views → Info only (no click)
- Twin Performance → Combined card showing:
  - Memory: X facts learned
  - IQ Growth: +X% this week

### Section 3: Your AI Twin (enhanced)
```
┌─────────────────────────────────────────────────────────┐
│  Your AI Twin                                          │
│  ┌──────────────┬──────────────────────────────────┐  │
│  │ Avatar + Info │ Quick Actions (4 buttons)       │  │
│  │ - Name        │ [Start Chat] [Analytics]       │  │
│  │ - Handle      │ [Manage] [Style Settings]      │  │
│  │ - Status      │                                  │  │
│  └──────────────┴──────────────────────────────────┘  │
└─────────────────────────────────────────────────────────┘
```

Quick actions (4 buttons in 2x2 grid):
1. 💬 Start Chat → `/chat-enhanced`
2. 📊 Analytics → `/analytics`
3. ⚙️ Manage Twin → `/twin/manage`
4. 🎨 Style Settings → `/twin/{id}/style-customize`
